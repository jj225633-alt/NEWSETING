# 星汐電腦版（Windows）

在電腦上開啟手機裡的 星汐。聊天、記憶和設定都只存在手機上，電腦版只是另一個畫面，所以**兩邊永遠是同一份聊天**，在電腦上說的話，手機上的 AI 都知道。

另外可以選擇把「電腦正在用什麼程式、用了多久」分享給手機上的 AI，讓它知道你在電腦上做了什麼。

## 安裝

執行 `dist/星汐 Setup <版本>.exe`（目前為 0.3.1）。安裝程式沒有數位簽章，Windows 可能顯示「Windows 已保護您的電腦」，按「其他資訊 → 仍要執行」即可。

## 第一次設定

1. 手機：設定 → Web伺服器 → 設定存取密碼、開啟密碼認證 → 啟動。
2. 電腦版第一次開啟會出現設定頁：
   - 家裡 Wi-Fi 位址：手機網頁服務頁上的「區域網路位址」。
   - Tailscale 位址（可選）：手機網頁服務頁上的「Tailscale 位址」，外出時用。
   - 密碼：手機網頁服務的存取密碼。
3. 按「測試連線」確認，再按「儲存並連線」。
4. 第一次進入聊天畫面時，網頁版會再請你輸入一次密碼登入。

之後開機會自動在背景啟動（可在設定關閉），點系統匣圖示就能開啟。關閉視窗只會縮到系統匣，要完全結束請在系統匣選「結束」。

## 分享電腦活動給 AI

1. 電腦版：設定頁勾選「分享目前使用的程式和使用時間」（系統匣選單也能隨時開關）。
2. 手機：助手設定 → 本機工具 → 開啟「電腦活動」。
3. 之後 AI 可以用 `pc_activity` 看到：目前使用的程式與視窗標題、是否閒置、最近的使用時間軸、今天各程式用了多久。

隱私說明：

- 每 5 秒看一次前景視窗；超過 5 分鐘沒操作或螢幕鎖定視為離開，不記錄。
- 不想分享視窗標題（例如網頁或文件名稱）可取消「也分享視窗標題」，只回報程式名稱。
- 「不分享的程式」清單裡的程式完全不記錄。
- 資料每分鐘送到手機一次，只存在手機（最近 48 小時），不經過任何雲端。手機連不上時，電腦端最多暫存 6 小時後再補送。
- 只在手機開啟「密碼認證」時才接受回報。

## 讓 AI 看螢幕

助手開啟「電腦活動」後，AI 可以用 `pc_screenshot` 請求看你的電腦畫面（例如你問「幫我看看這個網頁在講什麼」）。

- 電腦上會跳出「AI 想看你的螢幕」視窗並顯示 AI 寫的原因，選項有：允許這一次、一小時內都允許、拒絕。
- 允許後截下滑鼠所在的那個螢幕（寬度超過 1920 會縮小），傳到手機給 AI，並跳出通知告訴你已傳送。
- 90 秒內沒回應視為不同意；前景程式在「不分享的程式」清單中時自動拒絕。
- 不想讓 AI 請求截圖：取消設定頁或系統匣的「允許 AI 請求看螢幕」。

## MCP 工具橋接

很多大家分享的 MCP 工具要在電腦上執行指令（`"command": "npx"` 之類），手機跑不了。電腦版可以代為執行，再交給手機上的 AI 使用。

1. 電腦版：系統匣 →「設定…」→「MCP 工具橋接」，勾選「啟用」，貼上分享的 MCP 設定 JSON，按「套用橋接設定」。
2. 第一次 Windows 防火牆會詢問，請允許「私人網路」。
3. 狀態列表顯示每個工具是否「執行中」；成功後會自動登記到手機，手機的 MCP 清單會出現「名稱（電腦）」。
4. 手機：到助手的 MCP 設定勾選這些工具，AI 就能使用。

說明：

- `npx` 類工具需要 Node.js；`uvx` 類（Python）工具需要先安裝 uv。第一次啟動要下載套件，可能要一兩分鐘。
- 這些工具以你的 Windows 帳戶權限執行（例如檔案系統工具可以讀寫你的檔案），只加入你信任來源的工具。設定 JSON（可能含金鑰）以 Windows 帳戶加密儲存。
- 手機以隨機權杖連到電腦（預設連接埠 8765），只在家用 Wi-Fi 或 Tailscale 內可用；電腦切換網路時會自動更新手機上的網址，保留你在手機上的工具設定。
- 用的時候電腦要開著、電腦版要在執行；取消「啟用 MCP 工具橋接」會停止所有工具並從手機移除。
- 網址型工具（`"url": ...`）不需要橋接，請直接在手機：系統設定 → MCP → 匯入。

## 從原始碼建置

```text
cd desktop
npm install
npm install-scripts approve electron   # 新版 npm 預設阻擋安裝腳本；Electron 需要它下載執行檔
npm run dist                           # 產生 dist/星汐 Setup <版本>.exe
```

開發時可用 `npm start` 直接執行。
