星汐電腦版

電腦版會開啟手機上 星汐 的網頁版，聊天資料都在手機上，兩邊是同一份。請先在手機：設定 → Web伺服器，設定密碼、開啟密碼認證並啟動。

連線到手機

會依序嘗試，先連得上的就用哪個。
以 Windows 帳戶加密儲存在這台電腦，只用來向你的手機登入。

分享電腦活動給手機上的 AI

每 5 秒看一次前景視窗，超過 5 分鐘沒操作或鎖定螢幕視為離開。每分鐘送到手機一次，資料只存在手機（最近 48 小時）。AI 需要在助手的本機工具開啟「電腦活動」才讀得到。

MCP 工具橋接（讓手機使用需要在電腦執行的工具）

貼上別人分享的 MCP 設定 JSON（Claude Desktop、Cursor、VS Code 格式皆可）。其中 command 型的工具（npx、uvx、node、python…）會在這台電腦執行，並自動登記到手機的 MCP 清單，名稱後面會加「（電腦）」。網址型工具請直接在手機的 MCP 匯入。
注意：這些工具以你的 Windows 帳戶權限執行，可能讀寫你的檔案或操作電腦，只加入你信任來源的工具。第一次啟用時 Windows 防火牆會詢問，請允許「私人網路」，手機才連得進來。
手機端：之後到助手的 MCP 設定勾選這些「（電腦）」工具，AI 才會用到。電腦需開機、星汐電腦版需執行中。
